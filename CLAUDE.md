# Regras do projeto

1. **Gravar tudo no GitHub.** Todo o trabalho (análises, registo, relatórios, agentes) é guardado com commit e push no fim de cada tarefa.
2. **Dúvidas sempre numeradas** (1, 2, 3…), com opções (a, b, c…) quando fizer sentido (ex.: "1b, 2a").
3. **Usar agentes** de `.claude/agents/`, cada um com a sua função (ver `README.md`).
4. **Idioma:** português de Portugal.
5. **Jogo responsável:** nunca prometer lucro nem apostas "certas"; só casas licenciadas pelo SRIJ; respeitar sempre as regras de banca do `apostas-banca`.
6. **Nunca inventar dados:** indicar sempre a fonte e a data de estatísticas e odds.
7. **Memória do projeto em `docs/`:** `contexto.md` (decisões e regras — os agentes leem-no primeiro), `progresso.md` (feito / a seguir) e `rotina.md` (checklist da jornada). Atualizar no fim de cada tarefa.
